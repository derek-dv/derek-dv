### 🚀 Highlighted Projects

#### 💳 [Dora — Full-Stack Fintech Platform](https://github.com/derek-dv)
A financial platform built to handle ledger accounting, multi-currency wallets, and core banking integrations.
- **Tech Stack:** `Node.js` • `TypeScript` • `PostgreSQL` • `Redis` • `React Native`
- Engineered strict network idempotency engines and retry mechanisms to eliminate double-spend vulnerabilities.
- Normalized internal ledger balances to integer subunits to ensure zero-drift accounting.
- Integrated third-party BaaS APIs for dynamic virtual account provisioning and outbound settlement.

- Built interactive real-time score auditing tools with responsive client-side state management.
